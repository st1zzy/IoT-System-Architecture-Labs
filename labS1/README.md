# Lab S1. LPWAN — симуляция и энергопрофилирование

Отчёт: [LabS1_Жанайдаров_Амирлан.docx](LabS1_Жанайдаров_Амирлан.docx) · вариант: software-only (§26 силлабуса)

Дискретно-событийная модель LoRaWAN-сети EU868 с одним шлюзом и энергомодель устройства класса A.
Принятые шлюзом кадры через модель Network Server публикуются в MQTT стенда курса.

```text
[N end-devices] → [ALOHA: 8 каналов, SF ортогональны, захват 6 дБ] → [шлюз: 8 демодуляторов]
      ↓                                                                     ↓ ns_bridge.py
[энергомодель: фазы класса A]                    mosquitto: application/lab-s1/device/+/event/up
      ↓                                                                     ↓
[срок службы, графики]                                       app_counter.py: PDR по разрывам fCnt
```

## Запуск

```bash
pip install -r tools/requirements.txt
python tools/lorawan.py          # ToA, чувствительность, дальность, E_msg по SF
python tools/experiments.py      # все эксперименты → results/*.json (≈ 3 мин)
python tools/plots.py            # графики → report/img/

docker compose up -d mosquitto   # стенд для части Network Server → MQTT
docker compose --profile tools run -d --name labs1-app sim python tools/app_counter.py --idle 5
docker compose --profile tools run --rm sim python tools/ns_bridge.py --n 1000 --hours 1
docker logs labs1-app
```

## Модель

| Элемент | Как моделируется |
|---|---|
| Время в эфире | Формула Semtech SX1276: преамбула 8 символов, CR 4/5, LDRO для SF11–12; PHY 20 Б |
| Покрытие | Окумура–Хата, город, 868 МГц: PL = 126,0 + 35,2·lg d (км); 14 дБм; SF7 2,1 км … SF12 5,1 км |
| Доступ | ALOHA: периодически со случайной фазой и джиттером ±10 %, случайный из 8 каналов |
| Коллизии | Перекрытие на том же канале и SF; захват — если сильнее каждого мешающего на ≥ 6 дБ |
| Шлюз | SX1301: не более 8 одновременных приёмов на все каналы и SF |
| ADR | Наименьший SF с запасом ≥ 10 дБ над чувствительностью |
| Энергия | Фазы §14.3.2: опрос 8 мА, TX 45 мА × ToA, RX1/RX2 12 мА × 8 символов (RX2 на SF12), сон 2 мкА |

Проверка: чистая ALOHA — максимум S = 0,1833 при G = 0,5 (теория 1/(2e) = 0,1839);
ёмкость шлюза без захвата совпадает с аналитикой ALOHA с расхождением ≤ 2,5 %.

## Результаты

| Показатель | SF7 | SF9 | SF12 |
|---|---|---|---|
| ToA (PHY 20 Б) | 56,6 мс | 185,3 мс | 1318,9 мс |
| Устройств на шлюз при PDR ≥ 95 %, 1 раз в 10 мин | 2828 | 873 | 122 |
| То же, 1 раз в час | 17176 | 5200 | 718 |
| E_msg | 2,39 мкА·ч | 4,08 мкА·ч | 19,01 мкА·ч |
| Доля RX-окон в энергии сообщения | 38 % | 24 % | 10 % |
| Срок службы, 1 сообщение в час (3000 мА·ч × 0,75) | 59 лет* | 42 года* | 12 лет |

\* фактически ограничено сроком годности батареи (~10 лет).

- Эффект захвата увеличивает ёмкость шлюза на 29–36 %.
- Сота 3 км, 2000 устройств: ADR — PDR 84,6 %, «все на SF12» — 47,5 % при +76 % энергии сообщения.
- Приложение по разрывам fCnt оценило PDR в 89,4 % при фактических 66,5 %: молчащие устройства не видны.
