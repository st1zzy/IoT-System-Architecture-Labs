# Lab 8. Edge Processing

Отчёт: [Lab8_Жанайдаров_Амирлан.docx](Lab8_Жанайдаров_Амирлан.docx) · вариант: software-only

```text
 сеть site (объект)                                            сеть wan («облако»)
 [sim: 200 устр. × 5 метрик, 1 Гц] ─▶ [local] ─▶ [edge-agent] ─MQTT: только результаты─▶ [cloud] ─▶ [cloud-svc] ─▶ [TimescaleDB]
                    ◀── cooling_on (локальное правило, без облака) ──┘
```

Edge-агент: окно 60 с → min/max/avg/std/p95; детектор (spike: z-score к EWMA, drift: две EWMA, stuck: 15 одинаковых
значений) → аларм немедленно + сырое окно ±30 с; правило «температура > 80 °C → cooling_on»; store-and-forward (SQLite, PUBACK).
Детектор `common/detect.py` — один код для edge и облака.

## Запуск

```bash
docker compose up -d --build
python tools/tune.py --seeds 1 2 3 4 5           # офлайн-подбор порогов на модели (без Docker)
python tools/run_experiments.py                  # 4 прогона по 10 мин: edge-1..3, raw-1 (~50 мин)
python tools/analyze.py                          # метрики и графики (pip install -r tools/requirements.txt)
docker exec lab8-edge wan delay 40 10            # WAN 40±10 мс в каждую сторону; wan down / wan up
```
